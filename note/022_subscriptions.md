# 022 サブスクリプション管理（サブスクタブ）

## 目的
Netflix や Spotify などの定期支出を登録し、毎月の固定費の合計と次の請求日を一目で分かるようにする。カード明細の履歴と結び付けて、決済が記録されているかも確かめられるようにする。

## 変更内容
- `migrations/010_subscriptions.sql`（新規）、`schema.sql`: `subscriptions` テーブル（名前・金額・周期 `monthly`/`yearly`・請求日・年払いの請求月・カテゴリ・照合キーワード・色・URL・メモ・`active`）と、anon の select/insert/update/delete のポリシーと権限。
- `lib/subscriptions.ts`（新規）: 型、色の候補、毎月換算・年間換算、次の請求日 `nextBilling`・前回の請求日 `prevBilling`・残り日数・周期の進み具合の計算、キーワード照合。
- `components/SubscriptionTab.tsx`（新規）: サブスクタブの画面。
  - 上部の黒いまとめカード: 毎月の固定費、年間、利用中の件数、次の請求（日付とサービス名）。
  - 追加・編集フォーム: サービス名、色（12 色から選ぶ。頭文字のアイコンに使う）、金額、月払い/年払い、請求日（年払いは月も）、カテゴリ、照合キーワード、管理ページ URL、メモ。
  - 候補: 「サブスクリプション」カテゴリの履歴で、同じ店名が 2 か月以上あり、どのサブスクのキーワードにも一致しないものを提案する。タップでフォームに埋める。× で隠す（隠した状態は保存しない）。
  - 一覧: 次の請求日が近い順。カードに次回の日付と残り日数（3 日以内は橙色）、下に周期の進み具合の線。開くと、カテゴリ・毎月換算・最終決済（履歴から照合）・今回分が履歴にあるか・メモ・キーワードと、編集 / 一時停止（再開）/ 管理ページ / 削除のボタン。今回分が履歴にないときだけ「◯/◯ 分を支出として記録」ボタンを出す。
  - 一時停止中のサブスクは薄く表示し、固定費に数えない。
- `components/ExpenseApp.tsx`: タブに `subscription`（表示名「サブスク」）を追加。スワイプの順序の末尾に入れた。
- `README.md`: 機能一覧にサブスクタブを追加。既存ユーザー向けに未適用のマイグレーションを流す手順を追記。

## 設計判断
- **請求日は「日（と年払いの月）」で持ち、次回・前回の日付は端末で計算する。** 次の請求日の列を DB に持って毎回更新する方式は、更新を忘れると狂うため採らなかった。月末より大きい日（31 日など）は、その月の月末に丸める。
- **次の請求日は今日を含む。** 今日が請求日なら「今日」と出す。前回の請求日は、次の請求日から 1 周期戻した日。
- **履歴との照合はキーワードの部分一致（大文字小文字を区別しない）。** 既存の `category_rules` と同じ考え方で、カード明細の店名表記（例: `NETFLIX.COM`）を素直に拾える。空なら名前そのものをキーワードにする。
- **「今回分が履歴にある」の判定は、今回分の請求日の 3 日前以降に一致する決済があるかで決める。** カードの通知が請求日より少し早く届くことがあるため、猶予を置いた。今回分の請求日は、今日が請求日なら今日、そうでなければ前回の請求日。
- **候補の提案は「サブスクリプション」カテゴリに限る。** 全カテゴリで同じ店名の繰り返しを探すと、コンビニやスーパーが候補に出て邪魔になる。
- **「支出として記録」は手入力（`source: manual`、支払い方法「その他」）として追加する。** カード・銀行の自動取り込みと二重になる危険があるので、ボタンの下に注意書きを置き、今回分が履歴にあるときはボタンを出さない。
- **固定費はサブスクタブの中だけで集計し、月の合計やカテゴリ別には混ぜない。** 実際の支出は履歴に入る決済そのもので数えるのが既存の方針なので、登録情報は「予定」として扱う。
- 照合に使う履歴は、月次推移タブと同じく直近 13 か月ぶんを 1000 件ずつ全件取得する。個人利用の件数ならクライアント側の照合で十分。
- 色は `lib/subscriptions.ts` の 12 色から、未使用のものを登録順に割り当てる。カテゴリの色とは独立にした（サービスの印象に近い色を選べるようにするため）。

## 注意点・残課題
- 手順: Supabase の SQL Editor で `migrations/010_subscriptions.sql` を実行する。実行前にサブスクタブを開くと、テーブルがないというエラーが表示される。
- 候補を × で隠した状態はページを閉じると戻る。
- 年払いの請求月が 2 月で請求日が 29〜31 日のときは 2 月 28 日（閏年は 29 日）になる。
- 請求日の変更（例: プラン変更で日付がずれた）は編集で直す。過去の履歴は変わらない。
- 「最終決済」は金額がプラスの履歴だけを見る（返金は除く）。
